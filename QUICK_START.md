# 🚀 Быстрый старт - Сборка проекта v0.0.2.6

## 📦 Установка зависимостей

```bash
npm install
```

## 🔧 Команды сборки

### Режим разработки (с hot-reload)
```bash
npm run dev
```
- Запускает локальный сервер на `http://localhost:3000`
- Автоматически открывает браузер
- Мгновенное обновление при изменении файлов

### Production сборка
```bash
npm run build
```
- Создаёт оптимизированную версию в папке `dist/`
- Минифицирует JS и CSS
- Добавляет хэши к именам файлов
- Сортирует ассеты по типам

### Предпросмотр сборки
```bash
npm run preview
```
- Открывает собранную версию для тестирования

### Очистка
```bash
npm run clean
```
- Удаляет папку `dist/`

## 📋 Чеклист перед обновлением версии

1. **Обновите версию в `package.json`**:
   ```json
   {
     "version": "0.0.2.6"
   }
   ```

2. **Обновите версию в `index.html`**:
   Найдите `<span id="versionNumber">0.0.2.5</span>` и замените на `0.0.2.6`

3. **Обновите `CHANGELOG.md`** с описанием изменений

4. **Запустите сборку**:
   ```bash
   npm run build
   ```

5. **Протестируйте**:
   ```bash
   npm run preview
   ```

6. **Задеплойте** на хостинг

## 🐛 Решение проблем

### Ошибка: "Cannot find module..."
Убедитесь, что все зависимости установлены:
```bash
npm install
```

### Ошибка: "Script can't be bundled"
Добавьте `type="module"` к тегу `<script>` в HTML:
```html
<script type="module" src="Scripts/checkProtocol.js"></script>
```

### Большой размер бандла (>500KB)
Это нормально для Three.js проектов. Лимит увеличен до 1000KB в конфиге.

### Не загружаются текстуры/модели
Проверьте, что `base: './'` установлен в `vite.config.js`
