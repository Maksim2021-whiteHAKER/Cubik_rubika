# 🚀 Инструкция по сборке проекта (v0.0.2.5 → v0.0.2.6)

## ✅ Что добавлено в версии 0.0.2.5

### 1. **Система сборки на Vite**
- Быстрая сборка проекта с оптимизацией
- Автоматическое сжатие JS, CSS и изображений
- Хэширование файлов для кэширования
- Поддержка hot-reload для разработки

### 2. **Новые скрипты в package.json**
```bash
npm run dev      # Запуск сервера разработки (localhost:3000)
npm run build    # Сборка production-версии в папку dist/
npm run preview  # Предпросмотр собранной версии
npm run clean    # Очистка папки dist/
```

## 📦 Как собрать проект для версии 0.0.2.6

### Шаг 1: Обновите версию в package.json
Перед сборкой измените версию на `0.0.2.6`:

```json
{
  "version": "0.0.2.6"
}
```

### Шаг 2: Установите зависимости (если ещё не установлены)
```bash
npm install
```

### Шаг 3: Запустите сборку
```bash
npm run build
```

После сборки в папке `dist/` появится готовая к деплою версия:
```
dist/
├── index.html          # Главный HTML файл
├── js/                 # Сжатые JS файлы с хэшами
│   ├── main.[hash].js
│   └── chunks...
├── images/             # Оптимизированные изображения
├── models/             # 3D модели (.glb/.gltf)
└── audio/              # Аудиофайлы
```

### Шаг 4: Протестируйте сборку локально
```bash
npm run preview
```
Откроется браузер с предпросмотром собранной версии.

## 🐛 Возможные проблемы и решения

### Проблема: Ошибка импорта модулей
**Решение:** Убедитесь, что в `index.html` скрипты подключены как модули:
```html
<script type="module" src="/main.js"></script>
```

### Проблема: Не загружаются текстуры/модели
**Решение:** Проверьте пути в конфиге `vite.config.js`:
```javascript
base: './', // Для относительных путей
```

### Проблема: Большой размер бандла
**Решение:** 
- Включите код-сплиттинг
- Настройте lazy loading для тяжёлых ресурсов
- Оптимизируйте текстуры (до 256px для мобильных)
