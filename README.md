# Кубик-Рубика 3D

**Кубик-Рубика** - браузерная игра для развития памяти и логики: классический кубик с перекраской граней и текстурированные кубики, собирать которые заметно сложнее.

## 🌐 Демо
[Открыть в браузере](https://Maksim2021-whiteHAKER.github.io/Cubik_rubika/)

![Deploy](https://github.com/Maksim2021-whiteHAKER/Cubik_rubika/actions/workflows/static.yml/badge.svg)
![фото куба](/public/textures/cube.jpg?raw=true)

## ✨ Возможности
- 🧩 Обычный и свободный режимы, автосборка, таймер решения
- 🎨 Темы кубика (default / cars / gems / anime / custom ) и палитры (классика / неон / монохром)
- 🎡 Колесо фортуны, валюта, открываемые темы
- 🌍 Локализация RU / EN ( и еще 9 языков)
- 🔊 Музыка и звуки с пресетами громкости
- 📱 Адаптив под мобильные устройства

## 🕹 Управление [действие] -> (клавиша выполнения)
- [Вращение камеры] -> (ПКМ + тянуть)
- [Зум(увеличение\уменьшение)] -> (Колёсико мыши)
- [Орбита вкл\выкл] -> (Щ \ О)
- [Сброс камеры] -> (К \ R)
- [Автосборка по обратному ходу (свободном режиме)] -> (С \ C)
- [Разборка кубика] -> (Ы \ S)
**Режим вращения граней выбирается в настройках: триггеры на кубе или движение мыши.**

## 🛠 Технологии
Three.js · cannon-es (физика) · Vite · GitHub Pages + Actions (CI/CD)
Vitest — юнит-тесты (парсер версии, ядро кубика)

## Приватность
Приложение использует Яндекс.Метрику для анонимной статистики посещений
(webvisor, clickmap). Никакие персональные данные не собираются.

## 🚀 Запуск локально
```bash
# Клонирование репозитория
git clone https://github.com/Maksim2021-whiteHAKER/Cubik_rubika.git
cd Cubik_rubika

npm ci
# Запуск dev-сервера
npm run dev        
```
